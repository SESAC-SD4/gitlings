git pull을 실행해 보세요.
· mac에서 "fatal: Need to specify how to reconcile divergent branches." 에러가 나면
  다음 힌트로 넘어가세요.
· Windows(Git Bash)에서 편집기(VSCode 등)가 열리면 그냥 저장 후 닫으면 됩니다.

mac에서 fatal 에러가 났다면, pull 방식을 한 번 설정해야 합니다:
  git config --global pull.rebase false
  그 다음 다시:
  git pull

마지막으로 원격에 올립니다:
  git push origin main
